# API Integration — Day 9

## Objective

Demonstrate REST API integration using Angular and TypeScript.

## API Used

JSONPlaceholder demo API:
`https://jsonplaceholder.typicode.com/posts`

## Implementation

* Angular HttpClient
* FacilityService
* TypeScript interfaces
* RxJS Observable and map
* API response transformation
* Loading state
* Error handling and retry button

## How It Works

The Angular application requests sample data from JSONPlaceholder and transforms the response into facility records for the dashboard.

## Important Note

This is a practice integration using demo data. It is not a real facility inspection API.

Inspection history is stored in browser LocalStorage, not in a backend database.
