# Day 6: TypeScript and React Employee Management Dashboard

## Project Overview

This project demonstrates TypeScript fundamentals and a React-based Employee Management Dashboard. It covers TypeScript data types, interfaces, functions, generics, and React application development.


## TypeScript Concepts

* Basic data types: string, number, boolean
* Interfaces and objects
* Arrays and functions
* Union types
* Generic functions
* Generic interfaces and classes
* Employee data management

## React Dashboard Features

* Employee statistics dashboard
* Search employees by name
* Filter employees by department and status
* Sort employee records
* Add, edit, and delete employees
* View employee details
* Store employee data in browser localStorage

## Technologies Used

* TypeScript
* React
* Vite
* HTML
* CSS
* JavaScript
* Lucide React

## How to Run the React Application

Open the terminal inside the `react-app` folder.

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in the terminal.

## Production Build

To check whether the React application builds successfully, run:

```bash
npm run build
```

## Learning Outcome

This project provides practical experience with TypeScript fundamentals, React components, typed data, employee management operations, and frontend application development.
